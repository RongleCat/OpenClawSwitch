# Git 安装必须成功

日期：2026-03-08

## 结论

在一键安装流程里，`Git` 不是可选项，而是强依赖。

如果 `Git` 安装失败，安装流程必须立即终止，不能再继续安装 `Node.js`、`OpenClaw` 或后续组件。

## 之前反复出现的原因

此前 `install_git()` 本身已经会返回错误，但总安装流程 `run_full_install()` 把这个错误吞掉了，并继续往后执行。

也就是说：

- 单独安装 Git 会报错；
- 但一键安装会把 Git 失败当成 warning；
- 结果就是日志里明明提示 Git 失败，流程却继续跑下去。

这会造成两个问题：

- 用户误以为整体安装成功；
- 后续依赖 Git 的步骤会在更后面以更隐蔽的方式失败。

## 当前约束

当前实现已经改成：

- `install_git()` 失败时，`run_full_install()` 直接返回错误；
- Git 步骤进度标记为 `error`；
- 不再输出“Git 不是阻塞项，继续安装后续组件”这一类日志。

## 回归保护

已添加回归测试：

- `src-tauri/src/installer.rs` 中的 `git_install_failure_is_blocking`

这个测试保证：

- Git 安装失败一定被视为阻塞错误；
- 以后如果有人再把它改回 warning，测试会直接失败。
